## Candidate-generation changes

1. Use explicit native HiGHS `solver="ipx"` with presolve on, crossover off and
   IPM optimality tolerance 1e-10 for linearized AC correction subproblems.
   Installed HiGHS can route generic `ipm` to HiPO; this experiment requests IPX
   specifically and retains native evidence. Supply no primal/basis to that
   fresh LP. Preserve exact-domain/objective readback, conservative tiny-entry
   import auditing and <=1e-8 original linearization primal acceptance.
2. Use the original source shunt bounds continuously while constructing the
   first AC candidate. Run bounded network SLP. If needed, a same-attempt
   complete-primal Ipopt fallback uses the monotone barrier strategy and at most
   60% of then-remaining hourly time (also capped at 120 native seconds). This
   point is explicitly a candidate, not a valid final discrete output. The
   fixed-shunt feasibility callback is disabled in this unfixed phase.
3. Round every shunt to an integer inside its exact source domain, fix it, and
   update the complete primal mapping. Reject source domains without the chosen
   valid integral setting. Perform a new original-model residual audit and
   bounded IPX linear corrections. The rounded SLP receives at most 40% of the
   then-remaining hour, also capped by the SLP allowance.
4. If still needed, use the remaining hourly allocation for a fixed-shunt
   monotone-barrier Ipopt repair, at most 120 native seconds/600 iterations.
   Its early stop requires the existing complete original-model residual audit.
   Worse points are rolled back. The final discrete point, not its relaxation,
   must pass the unchanged <=1e-8 screen before any later hour proceeds.
