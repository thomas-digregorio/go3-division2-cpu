## Changes motivated by measured r04 phases

- Add an explicitly candidate-only continuous-shunt guard. On the current native
  iterate it independently audits the complete model at the stricter internal
  1e-10 target, with two consecutive objective observations within relative
  range 1e-7. It can stop candidate construction without waiting for a KKT proof.
  An unfixed/fractional shunt point is **not** declared an admissible discrete
  solution. The existing fixed-shunt guard still rejects unfixed-shunt use.
- After a returned continuous point passes that target, capture its complete
  finite current multipliers only if the current native primal exactly matches
  the selected point. Capture the old shunt bound identities before rounding.
  Missing, nonmatching or nonpassing native points do not provide this seed.
- Round/fix shunts in their exact original integer domains. With an available
  seed, skip the rounded SLP (r04 spent 17.992 s there without an accepted step)
  and go directly to same-hour primal/dual Ipopt repair. Only the old shunt bound
  rows may disappear and new fixed-shunt rows may appear. Audit all identities,
  restore the complete current primal, map old multipliers and initialize new
  fixed-shunt multipliers to zero. Use the existing tested small interior-push
  warm-start options rather than resetting to the ordinary large push. This is
  not a simplex basis or a promised reusable factorization.
- Approximate multipliers are initialization, **not** a dual bound/optimality
  certificate. Their mathematical validity as a certificate is not assumed.
  The final returned point must still pass the original discrete/nonlinear
  checks and exhaustive independent/official verification.
- Without a valid seed, retain the checked IPX rounded-correction/fallback path.
  The original fixed-first v1 and continuous-then-round v2 policies are preserved
  and independently tested. The new policy is
  `network_slp_continuous_hot_repair_v3`.

Fresh presolved IPX remains the initial linearized candidate method, with no LP
primal/basis start. Import auditing and original residual checks remain. r04's
first IPX call stopped with numerical no-progress, so no general claim that IPX
