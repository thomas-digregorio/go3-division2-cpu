## Evidence and change

r06 completed 17 locally screened hours but failed rounded-shunt hour 18 at
5.05843742971e-6 after 1,993.860098 end-to-end seconds. The solver log had
displayed original-constraint violations around 4e-11 during earlier iterates,
yet the guard made zero complete audits. The guard wrongly used small callback
`inf_pr` as a necessary prerequisite to auditing original feasibility.

Ipopt documents that callback `inf_pr` describes the scaled internal problem,
including its inequality-slack representation, whereas the default printed
residual describes original constraints. The installed Ipopt.jl wrapper
supports `GetIpoptCurrentViolations(..., scaled=false, ...)` and throws on a
failed native request. See the
[official TNLP documentation](https://coin-or.github.io/Ipopt/classIpopt_1_1TNLP.html).
The unrecorded r06 intermediate points are not retrospectively certified.

New policy: `network_slp_original_residual_guard_v5`.

- Preserve all v4 initialization, mapping, same-hour dual repair and rounding.
- In the native callback, periodically query original unrelaxed bound and
  unscaled constraint violations. Readbacks must be dimensionally consistent,
  finite and nonnegative; missing native results fail explicitly.
- When that cheap query passes 1e-10, perform the existing complete mapped
  original-JuMP primal audit. Only that audit, plus the existing objective-window
  condition, can stop a solve. The query alone is not a certificate.
- Log both internal callback and original residuals, probe counts/time and
  whether the old internal gate would have rejected the audited stop.
- Preserve the 1e-10 internal audit target, 1e-8 final local tolerance, complete
  independent/official final checks and all source equations/domains/penalties.
  No KKT/global-optimality or dual-bound claim is made.
- Older policies retain their original callback trigger for regression tests.

The native tiny regression deliberately creates a feasible original inequality
while Ipopt's internal slack residual remains larger. Both legacy and current
JuMP expression paths now stop only after the complete audit; 34 assertions
pass. Four additional assertions reject a genuinely infeasible original model.
An invalid policy is also rejected. The full time-varying tiny pipeline and
all prior regression paths must pass before the registered full run.
